# Digi Paradijs

Website van Digi Paradijs (digiparadijs.nl).

- `index.html` – de website
- `contact.php` – verstuurt het aanvraagformulier naar info@digiparadijs.nl
- `privacy.html` – privacyverklaring
- `embed.html` – lichte versie voor het telefoonscherm in de foto
- `img/` – foto's
- `portfolio/` – voorbeelden van klantwebsites

Plaats alle bestanden in de map `httpdocs` van de hosting.
